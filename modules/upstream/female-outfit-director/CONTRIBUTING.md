# 参与贡献

欢迎通过 Issue 或 Pull Request 改进女性换装导演。

## 适合提交的内容

- 修正文档、示例或安装步骤。
- 补充稳定、可复现的换装机制。
- 改善时间轴、动作连续性、服装物理和负面约束。
- 修复不同章节之间互相冲突的规则。

## 修改原则

- 保持 Skill 名称 `female-outfit-director` 不变，除非是经过讨论的破坏性升级。
- 用户明确参数必须高于默认参数。
- 参考图信息必须高于无参考图时的默认人物设定。
- 所有人物内容都应明确为成年人。
- 修改 M1 时，必须保持“复制副本飞入、原位置移除、换装后副本消失”的消耗式语义。
- 不要把仓库文档复制进 `skill/`；该目录只保留运行时所需文件。

## 提交前检查

1. 确认 `skill/SKILL.md` 的 YAML frontmatter 有效。
2. 确认 `SKILL.md` 与 `references/transition-library.md` 的机制描述一致。
3. 检查中文标点、时间点和人物数量是否自洽。
4. 不要提交参考人物照片、生成结果、压缩包、密钥或个人信息。

## Issue 建议格式

- 当前行为
- 期望行为
- 使用的输入提示词
- 涉及的换装机制和时长
- 可复现步骤
