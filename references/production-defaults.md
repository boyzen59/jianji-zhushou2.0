# 项目设置

每个项目保存一份 `production_policy` 与决定依据。固定出镜约定保留；其他设置按文案决定，续作保留用户已采纳的决定。

| 设置 | 新项目做法 |
|---|---|
| 引擎 | `engine: remotion`，母版使用Remotion，镜头可配合GSAP、Motion、Lottie、Canvas、SVG、Three.js |
| 画幅／帧率 | 由发布场景与源素材决定；无指定可用16:9、1920×1080、30fps，竖屏短片按9:16规划 |
| 真人 | 前15秒真人全屏，随后右下小窗；缺录像登记待录并继续其他部分。短于15秒的完整片在全片范围内保持真人全屏，片中摘例无需伪造开场 |
| AI片段 | 已有视频先探测源长，再按语义选择窗口；待生成片段按镜头动作估时。用户已指定时长直接登记；只有明确要求先确认时才等待 |
| 已约定的时长 | 保留依据和 asset_id→秒数；会改变该约定的剪辑先解决冲突。没有固定时长约定时可正常选段，不把整段源长当成必须完整播放 |
| 字幕／语言 | 按本次交付设 off、burned 或 external，预留真实安全区；双语按需求启用 |
| 声音 | 优先用户原声；没有配音可先估时。背景音乐、音效服务叙事，自动营销工具不覆盖已定文案或人声 |
| 风格预览 | 模型自主选择；确有方向问题一次性汇总MD供用户审批。用户明确要视觉稿时再输出，不预设5页 |
| 文字审阅 | 默认MD，按需粘贴或转换Word；不截图回看Word/PDF。要求全量校对时用文字ID与数据覆盖 |

涉及AI资产的前期规划默认给提示词及素材表：GPT图片提示词、Gemini视频提示词。用户指定Seedance时另做Seedance适配版。ViMax仅提供分镜规划方法；不启动其生成流水线。生成任务只有在用户实际要求生成时再使用相应工具，仍不默认调用上游付费服务。

schema 7保留presenter开场15秒与bottom_right_pip；AI策略按实际需求设置。`ai_video.duration_confirmation_required` 默认false；需要用户先确认的项目设true。已confirmed时保存 `confirmation_basis` 与 `durations_seconds` 并校验。详细字段与旧数据迁移见[数据与审阅](qa-and-schema.md)。

缺输入时先判断是否影响当前交付：没有录音不阻止分镜，没有未使用的AI片段不产生时长问题。不能实现的镜头记录缺项并继续其余工作。
