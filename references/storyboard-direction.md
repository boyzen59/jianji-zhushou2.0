# 从文案到镜头

先核对本次交付范围、原稿、原声、已定设置和素材状态，见[项目设置](production-defaults.md)。不先选模板再压文案。

## 语义拆解

原句使用稳定ID。每段提取：主张／证据／因果或对比／情绪／观众应新增的理解。已有录音以语义词或句锚定；已有可靠时间戳直接复用，没有录音可估时并标明精度。

按“原句 → 新理解 → 可见对象与关系 → 动作 → 可读结果”生成镜头。例如“费用增长来自重复环节”可让重复路径汇成成本，不能只放一个增长大数字。需要数值就查真实数据，没有数据用定性关系。证据本身清楚时允许静止。

需要新表现时查[语义地图](capability-map.md)，按关键词检索一组相关知识卡；不默认遍历所有仓库。已有合适机制可复用，普通镜头也可原创。重要镜头的选择理由写到分镜即可，不另填逐来源打卡表。

## 设计和节奏

用真实内容确定主视觉、字体、色彩语义、材质光向和运动语言，记录在 `art-direction.md` 与项目tokens。按[视觉标准](visual-style.md)落实主体、排版与运动；外部设计方案统一到这套体系再使用。

需要方向性意见时，把推荐方案、备选差异、素材缺项和需要用户作出的决定汇成一份MD，一次性展示。用户已选定或委托自主定稿就继续；不逐技能、逐镜询问。

节奏来自论证：建立空间 → 细看证据 → 动作推进 → 关系揭示 → 留出理解。开头、关键因果和结尾设计值得记住的视觉事件；不是每段都上高潮。短产品片可用[商业发布参考](motion-reference-index.md)，长解说保持章节张弛，不套短广告的快切密度。

## 分镜记录

使用[执行稿模板](../assets/templates/video-spec-template.md)，共用设置只记一次：

| 字段 | 内容 |
|---|---|
| 语义与时基 | source_ids、原句、视觉目的、原声／成片区间、cue精度 |
| 主体与素材 | 对象、前中后景、asset_id、真实素材／重建、到位状态 |
| 动作 | 起始 → 主要变化 → 阅读停留 → 结束；触发词、开始／高潮／落定帧 |
| 衔接 | 延续对象、视线落点、进入／退出状态；需要时硬切 |
| 实现 | knowledge_card、实际参考ID、Remotion组件、项目改编与验证状态 |
| 屏显与出镜 | text_id、语言、位置、安全区；真人需求仅在使用时登记 |

素材提示词按[prompt-direction](prompt-direction.md)制作；未知生成视频不依赖精确手势完成转场。参考视频按Hypit方法提取结构与语义锚点，再针对自己的文案设计，保留参考来源与差异。

## 实施和回修

先解决共用布局与时间轴，再扩展镜头；只为实际实现问题做针对性检查。相邻画面若只换字不换解释结构，回到语义对象重做；已经有效的镜头不用为变化而重做。

计划任务给可执行分镜；提示词任务给资产ID和可独立使用的提示词；预览任务给真实画面；成片任务继续到实际渲染与必要技术检查。恢复时复用仍有效的决定、ID与检查点。
