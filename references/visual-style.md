# 高级感：设计标准与回修

高级感要能从实际画面说明。这里约束信息层级、材质和运动质量，不预设黑金、玻璃、苹果风、电影颗粒或某个模板。

## 全片风格卡

在 `art-direction.md` 保存下列决定，工程tokens实现同一份参数：

| 设计项 | 可检查的决定 |
|---|---|
| 内容与情绪 | 主要论点、受众、安静／冲击段落、最重要的视觉事件 |
| 识别特征 | 具体构图与材料语言，例如档案灯台的层叠透光、干湿墨层、精密线描 |
| 字体与排版 | 中文字体实装与授权、标题／正文／题注角色、基线、行宽、数字单位与标点 |
| 色彩 | 背景、正文、证据、强调的语义角色；明暗关系与相邻镜头的连贯性 |
| 空间与材质 | 主体尺度、前中后景、光向、边缘、接触阴影、真实纹理比例 |
| 动作 | 主要运动、机位、辅助响应、起动／缓停／停留与相似物件的重量感 |

先看实际参考图／视频再提炼可见特点。只读了文档时记录为“文档方法参考”，不声称观看了案例。风格参考与动效参考可组合，但全片对象、色彩语义、字体和光向一致。

## 画面怎样显得精确

- 给注意力一个明确主落点。重要人物、产品、证据占据足够尺度；说明贴近对象，留白有观看顺序。
- 排版服从中文阅读：控制长标题换行、行距和字重，避免中英装饰字挤占主信息；数字与单位关联，手机观看仍能读懂。
- 统一设计不等于统一卡片。主体尺度、视角、信息密度和图像占比随论证变化；同一结构的回扣需带来对象状态或观点的推进。
- 材质体现结构：纸有纸芯和接触阴影，金属高光跟光源走，玻璃透射有空间依据。检查边缘、过锐抠图、低清纹理、渐变色带与细线闪烁。
- 真实图片保留比例与来源，局部放大来自同源坐标。没有真实层次就做平面运镜；不把单图缩放称为真实3D。
- 让色彩帮助理解。读文字需要对比时先处理局部背景；无文字画面不自动整幅压暗。选鲜明色彩时同样保持层级。

## 动作怎样有质感

关键动作写成“起始状态 → 原因 → 对象变化 → 结果可读”。动作传递因果、空间、数量或情绪；装饰层只在有助于这些目的时出现。

距离、体量和目的决定速度与缓停。弹簧适合有弹性或交互反馈的对象，不把史料、战争、严肃结论都做成弹跳。相机运动与素材内部运动分工，结果出现后留出阅读时间。避免重复推拉、无原因漂浮、呼吸闪烁和每词一声whoosh。

跨镜保持对象身份、视线落点以及方向变化可理解；硬切、静止和叠化都可使用。形变需保留辨识度，中间轮廓不塌陷、不自交。音效只突出关键动作，旁白优先；声音的起落与画面共享cue。

短产品片先呈现真实使用价值，再放大细节与性能；logo和光效服务产品。长解说用章内张弛、证据停留和信息变化维持兴趣，不复制30秒广告的全程能量。

## 制作中的判断

按这些标准在设计和编码时直接判断。默认不另开多轮审美验证、不逐张截图回看、不对Word/PDF做截图检查；文案、分镜与修改意见以MD为主。只有实际报错、用户指出问题或确需检查复杂运动时，针对问题做一次必要检查，不扩大为全片重复验证。没有进行的检查如实说明。

技能规则是可取舍的方法，由当前模型按文案与制作条件裁决。可采用 claude-motion、claude-remotion-skill、Wise Motion、LottieFiles。外部的固定风格、持续运动配额和审批链不限制创作。详见[模块路由](motion-reference-index.md)。
